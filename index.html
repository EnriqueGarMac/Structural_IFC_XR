Pulsa «Añadir elemento», selecciona el primer nodo sobre el modelo y desplaza el ratón o mando hasta el segundo nodo. Un clic final coloca la barra. Pulsa Esc para cancelar. Los nodos que no utilices no afectan al cálculo.

En Quest puedes señalar dos nodos consecutivos con el gatillo para crear el elemento seleccionado. También puedes seleccionar una barra para eliminarla. Los tirantes son más ligeros al utilizar secciones menores.
